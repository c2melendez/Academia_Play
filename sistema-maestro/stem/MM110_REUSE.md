# Inventario STEM para MM-110 M0–M1
Ejecutar `python sistema-maestro/stem/mm110_inventory.py`. Siete familias F01–F07, 13 referencias Git congeladas, límites de adaptación. Las referencias se inspeccionaron mediante GitHub; el validador comprueba estructura, no vuelve a recuperar blobs ni ejecuta los motores. El inventario es E2 estático, no PASS. Se conserva el oráculo local Q[x] y el worker limitado; PHUMA aporta patrones de repaso, Lite y Plus pruebas de expansión/factorización/división, sin transferencia de certificación. F02/F03 son reutilización interna. Las coincidencias de salida, el muestreo y la factorización no prueban todas las obligaciones curriculares. El dominio de una fracción original no se amplía por cancelación. Integrar en curriculum/mm110 solo tras revisar su propio contrato y estado; M2–M9 fuera de alcance.
