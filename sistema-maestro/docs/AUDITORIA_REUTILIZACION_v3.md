# Auditoría de reutilización de Precision Lab Lite/Plus

Registro de candidatos, no certificación de portabilidad.

- MathLive y editor natural de Lite: útil para introducir expresiones matemáticas, pendiente auditoría de dependencias y accesibilidad.
- KaTeX (Lite y Plus): representación matemática segura, comprobar fórmulas y lectura accesible.
- GraphViewer (Lite y Plus): gráficas de funciones con restricciones de dominio; adaptar modelo compartido y no imponer UI de calculadora a laboratorios.
- Oráculos de equivalencia simbólica, matrices y ecuaciones (Plus): útiles como punto de partida. Validar dominio, falsos positivos e INCONCLUSIVE.
- Historial, PWA y diseño móvil: comparar su encaje curricular.
- El timeout por hilos no termina físicamente SymPy; preferir aislamiento por proceso con límites y terminación real.

El código reutilizado debe auditarse contra la revisión exacta y licencia del repositorio, con pruebas nuevas. La certificación de Precision Lab nunca se transfiere automáticamente a Academia Play.
