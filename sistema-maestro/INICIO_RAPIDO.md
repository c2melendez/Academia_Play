# Inicio rápido — Academia Play v4.1

Esta guía **no sustituye** al orden normativo de `CONSTITUCION.md`. Un agente debe seguir: Constitución → Runbook → Gates → schemas → Prompt Maestro → AGENTS → continuity → infra/manifiesto activo.

1. Consultar `default_branch` y HEAD reales en GitHub; no inferirlos desde los archivos.
2. Leer `continuity.json` como checkpoint y reconciliar proveedores antes de afirmar estado actual.
3. Ejecutar `ESTADO` para informar sin escribir, `INICIAR` para plantear un primer curso real cuando se reciba sílabo y bibliografía, o `CONTINUAR` para trabajo habilitado.
4. No iniciar M0 curricular sin `APROBAR_DISEÑO` explícito para la revisión exacta.
5. Nunca inventar pruebas, permisos, firmas, CI, SHAs o despliegues; `E1` requiere evidencia observable y `NOT_RUN` no es `PASS`.

La fuente exclusiva de semántica de comandos es `RUNBOOK.md`; la de los gates es `GATES.md`. Los ejemplos son sintéticos y no constituyen certificación.
