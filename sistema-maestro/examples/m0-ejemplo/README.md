# Ejemplo M0 sintético — sin certificación

Esta carpeta documenta cómo se estructuraría un primer corte vertical. **No incluye un curso oficial, una autorización humana ni una ejecución de oráculo.**

La instancia de ejemplo de datos estructurales se conserva en `../manifest.json`; la plantilla de propuesta y los registros de gate están en `../../templates/`.

Para pasar a M0 real se requieren: sílabo vigente comprobado, bibliografía autorizada, 3 alternativas por familia, `APROBAR_DISEÑO` explícito para la revisión exacta, implementación de actividad/oráculo/progreso, pruebas E1, verificación de gates y revisión humana aplicable. Un ejemplo JSON sintácticamente válido no prueba ninguna de esas condiciones.
