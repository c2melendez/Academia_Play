# Academia Play

Plataforma de aprendizaje STEM lúdica, modular y rigurosa, adaptable a asignaturas de distintas universidades mediante sílabos y libros autorizados.

**Estado:** bootstrap de infraestructura y Sistema Maestro v4.2. Todavía no hay cursos certificados.

El agente debe consultar la rama predeterminada y el HEAD actuales en GitHub antes de trabajar. Los documentos históricos no tienen carácter normativo.

## Ejecución
1. Adjuntar sílabo y bibliografía autorizada de la asignatura.
2. Solicitar INICIAR; evaluar las alternativas educativas y aprobar explícitamente con APROBAR_DISEÑO.
3. Construir el primer ciclo vertical de aprendizaje y certificar las pruebas técnicas; la certificación docente queda separada.

Render publica únicamente una página provisional hasta que exista producto educativo verificado. Los PDF de terceros no se versionan en este repositorio.

**Prioridad v4.2:** restaurar aprendizaje de fundamentos, puentes conceptuales y experiencia interactiva mediante investigación didáctica. El sitio continúa provisional hasta una experiencia curricular real aprobada.
